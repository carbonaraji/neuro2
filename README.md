# 🍎🍐 Fruit Classifier: Яблоко vs Груша

Проект на базе **TensorFlow/Keras** для бинарной классификации изображений фруктов. Нейросеть (сверточная CNN) обучается отличать **яблоки** от **груш** по фотографиям и выдаёт предсказание с вероятностью принадлежности к каждому классу.

## ✨ Возможности

- 🧠 Обучение собственной сверточной нейросети с нуля
- 📊 Автоматическое разделение датасета на train/validation/test
- 🖼️ Аугментация данных для повышения качества модели
- 📈 Визуализация процесса обучения (графики loss и accuracy)
- 🔍 Тестирование модели на новых изображениях
- 💾 Сохранение и загрузка обученной модели

Заполните папки изображениями
dataset/apples/ — загрузите сюда от 100+ фотографий яблок
dataset/pears/ — загрузите сюда от 100+ фотографий груш
💡 Требования к изображениям
Параметр
Рекомендация
Формат
.jpg, .jpeg, .png
Разрешение
Не менее 128×128 пикселей
Фон
Разнообразный (стол, рука, дерево, упаковка)
Ракурс
Разные углы съёмки
Освещение
Разное (яркое, тусклое, естественное)
Количество
Чем больше — тем лучше (минимум 100 на класс)
⚠️ Важно: Количество изображений в папках apples и pears должно быть примерно одинаковым, чтобы избежать дисбаланса классов.
